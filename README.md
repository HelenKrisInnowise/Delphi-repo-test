## How It Works

The team routes work automatically based on your request:

- **"What should I do today?"** → Maya (daily planning)
- **"Implement feature X"** → Viktor (technical work)
- **"Write a blog post about Y"** → Luna (content creation)
- **"Should I pursue opportunity Z?"** → Marco (strategic decisions)
- **"How do I grow in skill A?"** → Sage (professional development)
- **"Follow up with person B"** → Kai (relationship management)
- **"Process meeting transcript"** → Kai (extract contacts & actions)

Just talk naturally — agents coordinate behind the scenes.
